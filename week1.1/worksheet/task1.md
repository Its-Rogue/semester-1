# Terminal Commands

You have been introduced to a variety of terminal commands this week – fill out the table with an explanation for each command which says what it is used for.

You may find it useful to run these commands in the terminal of Codespace to remind yourself.

You should put your explanations between the \| \| characters.

You can complete this task on the worksheet pdf if you prefer.

|     Command                 |     Explanation    |
|-----------------------------|--------------------|
|     pwd                     | shows the current location of the terminal |
|     ls                      | shows a list of the current processes running|
|     cd directory_name       | moves the active directory to directory_name|
|     cd ..                   | goes up 1 directory|
|     cd -                    | goes down 1 directory|
|     mkdir directory_name    | make a directory with name directory_name|
|     touch filename          | make a file in the current directory with the name filename|
|     git status              | prints a list of all modified files since the last commit|
|     git add -A              | add all files to a commit that have been modified|
|     git commit -m ""        | add a commit message|
|     git push                | push the commit to the repo|
|     git pull                | download the latest commit in the repo|
